# [SIP-52] Seamless DAO Sunset

## Summary

This proposal revokes all administrative access held by Seamless governance, leaving the Protocol in a dormant, withdrawal-only state and formally sunsetting Seamless DAO. The Protocol Guardians will step down and relinquish their remaining permissions.

## Proposal

If approved, this proposal authorizes the complete and irreversible removal of all privileged control over the remaining Seamless Protocol infrastructure.

### 1. Remove governance control
The Seamless Governor, Timelocks and all other governance-controlled contracts must permanently lose the ability to administer, upgrade or modify the Protocol. After execution, acquiring SEAM voting power must not provide any direct or indirect authority over the relevant contracts or user assets.

### 2. Remove Guardian powers
The Protocol Guardians will formally step down and relinquish all remaining roles, permissions, and administrative authority.

### 3. Preserve user exit functionality
This proposal must not transfer, seize or redistribute user assets. It must not alter user balances, forgive or transfer debt, or introduce any restrictions on users seeking to exit.

### 4. Seamless DAO wind down

Upon execution of this proposal, Seamless DAO will be officially sunset and will no longer be operational. Official support through Discord will end, and both the Discord server and Governance Hub will be permanently shut down.

The Seamless X account and GitHub repositories will remain accessible to provide users with instructions and resources for withdrawing any funds that remain in the Protocol.
